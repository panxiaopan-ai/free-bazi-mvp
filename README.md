# Free BaZi MVP

A fast static MVP for a Traditional Chinese BaZi calculator.

- Stack: Next static export + `lunar-typescript`
- Deploy target: GitHub Pages for same-day launch
- Live URL target: https://panxiaopan-ai.github.io/free-bazi-mvp/
- Sitemap: https://panxiaopan-ai.github.io/free-bazi-mvp/sitemap.xml

## Local

```bash
npm install
npm run build
```

## GitHub Pages build

```bash
GITHUB_PAGES=true NEXT_PUBLIC_BASE_PATH=/free-bazi-mvp npm run build
```
